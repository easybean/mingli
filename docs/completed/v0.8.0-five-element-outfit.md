# 0.8.0 五行穿搭整合

## 本轮完成

- 首页依次提供每日穿搭、紫灵牌问事、人生岔路、命盘入口；保留旧推演继续入口。底部首页真正返回首页。
- 同一弹窗提供今日通用色卡、个人搭配；「我的」复用个人搭配入口。
- 个人版复用 API 的五行色板，按已有命盘调候参考五行选择，展示衣服及配饰实例。
- 个人版不公开生日、时辰、出生地。固定长期参考，不伪造每日变化。允许同类人使用同色。
- 通用版按日支取色，个人版按出生资料调候取色；有交集时提示，无交集时不判冲突和禁忌。
- 删除可见的“当下最该补”“必然相生”“统一润燥”结论。缓存旧命盘也使用新的边界说明。
- 色卡打开、个人入口、保存点击、系统分享完成采用独立事件，不含出生字段。保存点击不表示保存成功，系统分享返回也不能证明实际发布。

## 依据与未解决边界

调候表是项目整理的日干×月支简化表，不等于全八字喜用分析。已做 120 格覆盖与天干数据结构校验，尚未完成对古籍各条原文及条件的逐项文献复核，页面不宣称权威或精准判定。材料五行不参与新版推荐，只按可见颜色映射。无有效参考数据时不生成个人结论。

图片仍在浏览器生成，无 AI 调用；本轮不改服务器预生成方案。
跨日留存需要后续确定匿名识别与隐私规则，本轮仅复用会话级事件，不宣称已能识别次日回访。
