# v0.10.0 紫灵牌互动抽牌

## 参考与范围

参考用户提供的本地 `taluo.mp4`（约 1 分 49 秒）的交互节奏：长按、洗牌、扇形挑选、背面确认、翻面和归阵。保留紫灵牌原有北斗七星美术，不复制 Takuku 的图片、音频或角色。录屏仅作参考，不提交 GitHub、不部署。

这一版只改抽牌体验，不更改牌义、问事解读、概率或命盘计算。不将长按时长、洗牌次数、选牌方向解释为预测准确度。

## 完整模式

1. 长按约 1.8 秒聚光：牌背中心逐渐发亮，描边进度增长，松手暂停，再按继续；提供轻点替代。
2. 互动洗牌：指针/手指来回拖动，牌组响应移动、旋转；完成一定手势距离后允许铺牌，也可轻点洗牌。
3. 五副牌库依次抽取：主星 16、甲级 14、乙级 32、丙级 17、四化 12。有限边界扇形浏览，支持左右拖动、前后按钮、位置滑杆及方向键/Home/End；所有牌可到达。
4. 点牌后仅放大牌背，可放回；确认后才翻面，选中牌身份保持不变。揭晓后确认收下，缩小归入对应位置。
5. 空宫出现后保留次数，由用户回到剩余主星手动再抽。已翻开的空宫移除，不重复抽回；主星落定后继续四类辅牌。
6. 简化模式继续保留，空宫仍需用户主动点击引星。

## 工程保障

- 手势监听与 RAF 每次换屏清理；返回/关闭取消延迟任务，窗口失焦和切后台停止长按/拖动。
- 拖动与轻点分离，滑动松手不误选；翻面/归阵期间防重复提交。
- 用命名空间状态类隔离其他模块的 `.reveal` 样式。
- `prefers-reduced-motion` 下取消空间移动与循环动效，保留操作语义；无需引入动画依赖。
- 手机界面纵向可滚动，扇形局部裁切，不制造页面横向溢出。

## 验证

- `npm run validate:ziling-ritual`：运行真实手势绑定的事件测试与控制器状态机，包括暂停/取消/后台、拖动洗牌、五牌库全量可达、拖动误触防护、两次空宫、重复点击防护、归阵、关闭清理、简化模式。
- `npm run verify`：包含上述回归，以及原抽牌、解读和项目完整回归。
- 浏览器人工验证：375×812 手机尺寸实际长按与拖动，320×568 小屏完成五类抽牌并检查 32 张末端可达、无横向溢出；日间主题与桌面宽度检查。
- 不是实体 iPhone Safari 实机测试；触觉与声音未新增。
