# 0.8.1 配色依据复核与可选回访统计

## 本轮交付范围

对照《穷通宝鉴》维基文库转录本（revision 2294674），复核 10 日干 × 12 节气月支的基础取法，保存 120 条检索词、参考天干和条件说明。不是全八字专家系统，也不是所有版本校勘完成。

固定版本：https://zh.wikisource.org/w/index.php?title=穷通宝鉴&oldid=2294674

审核数据：`data/knowledge-rules/bazi-tiaohou-audit.json`。旧表仅作差异对照，运行时不再调用。

### 结果

- 111 项提供有条件的基础配色参考，不称为精确喜用神。
- 9 项暂停自动个人取色：乙午、乙未、乙申、乙酉、丙亥、丁午、戊戌、己戌、庚巳。
- 与旧表相比，58 项天干列表或可用状态不同。差异包括删去条件用神、调整顺序、暂停输出，不等于旧表有 58 处可确定的古籍错误。
- 乙丑最初因转录缺口暂停，随后目视核对影印 PDF 第69页（书内第五十九页）及第46页乙木喜用提要，恢复基础丙。来源覆盖保存在 sourceOverrides，不冒称其依据是转录本独立十二月条。此次也目视检查了影印第25、70页相关上下文。
- 例如甲辰改为庚壬；己辰改为丙癸甲；辛酉仅保留壬作为基础，甲保留为条件而非固定色系。
- 每项可见条件及原文链接。缓存命盘也会按日干、节气月支重新请求当前依据，不沿用旧缓存中的配色结论。
- 争议项不会回退到另一种旺衰算法再冒充调候；通用日支色卡始终可用。
- 月支来自排盘月柱，不按用户填写的农历月数字查表。

## 回访统计

- 默认关闭，用户可在穿搭弹窗主动开启。
- 本机随机 UUID 有效 30 天，到期清除，不自动续期；不指纹识别、不跨站、不关联出生字段。
- 仅 `outfit_visit` 事件接受 visitorId，禁止同时携带故事、出生等字段。
- 关闭后移除本机标识并停止后续发送，既有日志按服务器现有 90 天策略清理（可由运维环境配置调整，部署前须核对）。
- `npm run analytics:summary` 显示穿搭动作和 D1 回访。
- D1 按北京时间自然日，分母为保留日志内首次观察到的、同意统计的浏览器标识。次日完整结束前标“观察中”，不把尚未到来的回访记为失败。
- 不是全站真实用户留存：拒绝统计、换设备、清缓存、标识过期、日志保留窗口均影响计数。
- 保存按钮只记保存点击；原生分享 Promise 返回只记系统分享返回，不能证明已发布。

## 验证

`npm run verify` 加入调候审核和回访回归。另以本次下载的原始 HTML 对119个转录本条目检索词做定位校验，乙丑使用影印页人工目视补证（定位校验不是底本文字真实性校验）。浏览器检查缓存刷新、暂停条目无图/禁用保存、通用版可用、统计开关及多宽度无溢出。

仍需完成的影印本校勘、条件建模和推广验证见 `docs/active/outfit-source-and-validation-followup.md`，不将其标记为已完成。
