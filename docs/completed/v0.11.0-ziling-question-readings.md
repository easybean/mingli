# v0.11.0 紫灵牌：先读问句，再读牌阵

- 旧版首段由意图和笼统顺逆生成，换问句也可能逐字相同。新版用问句匹配 16 个常见场景；未匹配则明确只做主题阅读，不把用户的问句替换成默认剧情。
- 主星决定看沟通、资源还是变化；甲乙丙辅星与四化决定哪些推动或牵制值得说。输出先答题，再解释牌面依据，最后给出一个现实可观察的信号。完整五牌依据按需展开。
- 问事入口移除「想推进／想退出」和关注点选择，保留自愿填写问句与复盘范围。没有外部模型调用，不新增问句上传。
- 抽牌仪式、空宫规则、本命宫对应不变。健康、安全、中奖、投资等不做结果预测；没有命盘时不冒充本命解读。
- 新记录标记为 reading-3，本机旧 reading-2 仍可查看、复盘，原文不重算。
- 回归覆盖不同问句配同阵、不同星组配同题、客户尾款分类冲突、普通联系不预设分手、空问句与敏感问句、旧记录兼容。
