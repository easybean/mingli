# 0.8.2 五行穿搭体验改进

- 将配色结果与操作置于长篇依据之前；依据仍平铺显示在图片下方，不删除、不折叠。
- 个人版允许在已审核参考色系之间选择主色，不额外增加命理结论。
- 日常、通勤、只加配饰三种搭配模板；不涉及预测吉凶，使用已有单品即可。
- 配套纯文本分享文案，默认不包含出生日期、地点等字段；剪贴板失败时显示手动复制文本。
- 请求失败可明确重试；12秒超时；切换和关闭时取消旧请求，防止旧响应覆盖新选择。
- 离开出生表单、选择故事或清除命盘时清除穿搭返回标志，避免后续排盘误入个人搭配。
- 分享图标题改为不依赖“今天”，避免明日色卡文案自相矛盾。

## 验证

`npm run verify` 增加 `validate:outfit-presentation`：5色系 × 3场景、非法选项回退、纯文本隐私边界。

`scripts/validate-outfit-browser.cjs` 为可重复的可选浏览器回归，需环境已有 Playwright 和 Chromium，不增加生产依赖。验证配色切换、场景、复制权限失败、请求失败重试、延迟请求切换、暂停条目、统计开关、320px弹窗与四种首页宽度。
