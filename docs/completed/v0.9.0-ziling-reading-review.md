# 0.9.0 紫灵牌问事与复盘

- 问句最多160字，增加意图、关注点和观察周期；均可保持默认继续。
- 五张牌共同提供阅读线索，分别解释主线、推动或牵制、变量、细节与四化；不再将禄权科统一判为吉。
- 结果先显示本阵摘要、值得留意的矛盾、可观察的下一步。命盘事实、随机牌象、用户填写内容分开展示。
- 7天/30天是用户选择的复盘间隔，不是应验时间。空宫轨迹保留，不当作现实必然延迟的证据。
- 本机记录需主动保存，最多20条；满额提示手动整理，不自动删除。原解读快照不因复盘或当前算法变化改写。可记录不符合、部分符合等反馈，可删除。
- 不同步云端，不附完整出生信息；但保存包含用户主动填写的问句和部分命盘解读，因此提醒避免填写他人敏感信息。
- 修复问句与复盘文本HTML转义；牌面资料标明不是对用户健康或财务结果的判断。
- 保留逐张/简化抽牌、北斗牌背和主动空宫补抽。

## 验证

`npm run verify` 全量回归。新增 `validate:ziling-reading` 覆盖81张实体牌、意图/关注点、敏感问题边界、记录上限、存储失败、原解读不可被复盘覆写。

`scripts/validate-ziling-browser.cjs` 使用环境已有Playwright，覆盖问句注入、手机宽度、简化抽牌、完整五轮抽牌、连续空宫主动补抽、主动保存、刷新回看、复盘、删除。

## 边界与后续

本版是可解释的规则模板，不是理解任意问句的语义模型；自由文本作为问题记录，结构化选择参与解读。没有接入流年流月，也没有证据宣称提高了预测准确率。敏感问句关键词只是基础防线，不是完整语义识别。记录仅在当前浏览器，清除浏览器数据会丢失；反馈不被包装成预测准确率统计。
