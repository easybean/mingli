# v0.10.1 扇形触屏滑动修复

- 根因：触屏会将 pointer 隐式捕获到牌按钮；拖动超过阈值后容器接管捕获，子按钮的 `lostpointercapture` 冒泡至容器，被错误地当成拖动结束。鼠标路径不一定触发这一序列。
- 修正：仅容器自身丢失捕获才结束拖动；超过阈值时仅接管一次；牌区使用 `touch-action: none`，避免斜滑被页面滚动抢走。牌区以外仍可正常纵向滚动。
- 回归：新增子牌捕获转交后继续移动的失败用例，修正前失败、修正后通过；覆盖真正丢失捕获、斜/竖滑不误选、轻点可选、32 张全量可达及原有五类抽牌流程。
- 验证范围：事件级触摸序列回归及浏览器拖动检查；当前内置浏览器不支持注入原生触摸，未宣称完成实体 iPhone Safari 实机验证。
